# Gandoni Quick Join

Клиентский Fabric-мод: добавляет в главное меню Minecraft кнопку
**«▶ <название режима>»**, по которой игрок сразу подключается к серверу режима.

Адрес сервера мод берёт из файла `config/gandoni-quickjoin.json`, который лаунчер
пишет в папку сборки перед запуском игры. Сам мод лаунчер тоже подкидывает
автоматически (см. `src-tauri/src/quickjoin.rs`) — вручную ставить ничего не нужно.

```json
{
  "host": "mc.example.com",
  "port": 25565,
  "label": "Выживание"
}
```

Если файла нет или `host` пуст — кнопка не показывается.

## Как это работает вместе с лаунчером

1. Игрок жмёт «Играть» на Fabric/Quilt-режиме, у которого задан сервер.
2. Лаунчер пишет `config/gandoni-quickjoin.json` и кладёт `gandoni-quickjoin-<версия>.jar`
   в `mods/` сборки.
3. В главном меню игры появляется кнопка — один клик, и игрок на сервере.

Мод только для клиента (`"environment": "client"`) и требует Fabric API.

## Сборка

Мод компилируется под конкретную версию Minecraft. Нужен JDK 17–21 и интернет
(Fabric Loom качает Minecraft и маппинги).

```bash
# из корня проекта; кладёт jar в src-tauri/resources/quickjoin/
JAVA_HOME=/path/to/jdk-21 GRADLE=/path/to/gradle tools/build-mod.sh \
  1.20.1  1.20.1+build.10  0.92.2+1.20.1
```

Аргументы: `<mc_version> <yarn_mappings> <fabric_api_version> [loader_version]`.
Версии маппингов/API смотри на https://fabricmc.net/develop/.

> ⚠️ Если путь к проекту содержит эмодзи или не-ASCII символы, Gradle падает на
> `setcwd()`. Скрипт это обходит — собирает во временной ASCII-папке.

### Про разные версии Minecraft

Внутренние API игры меняются между версиями, поэтому мод собирается отдельно под
каждую. Исходник рассчитан на **1.20.1**. Для 1.20.2+/1.21.x конструктор
`ServerInfo` принимает `ServerInfo.ServerType.OTHER` вместо `boolean` — поправь
одну строку в `QuickJoinClient.java` под нужную версию.

Собранные jar-ы лежат в `src-tauri/resources/quickjoin/gandoni-quickjoin-<mc>.jar`;
лаунчер сам выбирает файл по версии Minecraft режима. Нет jar под версию —
кнопки просто не будет, игра запустится как обычно.

## Проверено

Собран под 1.20.1 (Fabric Loom 1.7, Yarn `1.20.1+build.10`, Fabric API
`0.92.2+1.20.1`) и запущен на живом клиенте: мод грузится, читает конфиг и
добавляет кнопку в главное меню — в логе `Кнопка захода на сервер … добавлена в меню`.
