# Ассеты сервера

Файлы отсюда попадают в Docker-образ и раздаются страницей `/download`.

## `download-background.mp4`

Фон титульного экрана. Требования:

- **беззвучный** — видео проигрывается с `muted`, иначе браузер запретит автозапуск;
- **индекс в начале файла** — иначе браузер сперва тянет хвост, и старт заметно
  задерживается;
- **небольшой** — он приезжает каждому посетителю; 10–20 секунд в петле, 3–8 МБ.

Всё это делает одна команда:

```bash
ffmpeg -i исходник.mp4 -movflags +faststart -an \
  -vf scale=1920:-2 -c:v libx264 -crf 26 -preset slow \
  assets/download-background.mp4
```

Заменить фон на живом сервере, не пересобирая образ, можно положив файл с тем
же именем в `DATA_DIR` (`/srv/g-launcher/data/download-background.mp4`) — он
имеет приоритет над этим.

## `minecraft-react-ui.css`

Стили кнопок из [minecraft-react-ui](https://github.com/josempineiro/minecraft-react-ui)
0.6.0 (MIT, José Manuel Piñeiro Garcia). Скопированы как есть: страница
`/download` — обычный HTML, пакет к ней не подключить, поэтому её разметка
использует классы `.Button` из этого файла. В самом лаунчере стоит настоящий
компонент из пакета.

Обновить: `cp node_modules/minecraft-react-ui/build/minecraft-react-ui.css server/assets/`

## `secret-bg.jpg` и `secret-theme.mp3`

Пасхалка: двадцать нажатий на кнопку смены подписи в меню включают другой фон
и эту песню. Двадцать первое нажатие или `Esc` выключают обратно.

Трек — чужая запись, выложенная на публичный сайт. Права на него не наши,
так что при претензиях правообладателя файл придётся убрать.
